Developer REST API & Integration

Simple, standard HTTP endpoints to embed CAPTCHA into any web app, mobile app, or backend.

POST /api/captcha/generate

Generates a dynamic SVG CAPTCHA challenge and registers a single-use session token.

Request Body (JSON - Optional)

{
  "type": "alphanumeric", // "alphanumeric" | "numeric" | "alphabet" | "math" | "custom"
  "size": 5,              // Length (3 to 8)
  "noise": 3,             // Distortion lines (0 to 10)
  "color": true,          // Multi-color characters
  "background": "#f8fafc",// Background color
  "ttl": 300              // Validity in seconds (default: 300)
}

Response (200 OK)

{
  "success": true,
  "id": "7a8f192b-3c4d-4e5f-a6b7-8c9d0e1f2a3b",
  "svg": "<svg xmlns='http://www.w3.org/2000/svg'...</svg>",
  "type": "alphanumeric",
  "expiresIn": 300,
  "expiresAt": "2026-11-03T18:00:00.000Z"
}
POST /api/captcha/verify

Verifies the user solution against the session ID. Consumes session immediately on success.

Request Body (JSON - Required)

{
  "id": "7a8f192b-3c4d-4e5f-a6b7-8c9d0e1f2a3b",
  "answer": "8kX2p",
  "caseSensitive": false
}

Response (200 OK / 400 Bad Request)

{
  "success": true,
  "message": "CAPTCHA verified successfully!",
  "verifiedAt": "2026-11-03T17:45:00.000Z"
}

Integration Code Snippets

Copy-Paste Ready 
// 1. Generate CAPTCHA
const genRes = await fetch('/api/captcha/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ type: 'alphanumeric', size: 5, noise: 3 })
});
const { id, svg } = await genRes.json();

// Render SVG in your HTML container
document.getElementById('captchaContainer').innerHTML = svg;

// 2. Verify User Input
const verifyRes = await fetch('/api/captcha/verify', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    id: id,
    answer: document.getElementById('userCaptchaInput').value,
    caseSensitive: false
  })
});
const result = await verifyRes.json();
if (result.success) {
  alert('Verified! Proceeding with form submission...');
} else {
  alert(result.message);
}

import requests

BASE_URL = "http://localhost:3000"

# 1. Generate CAPTCHA
response = requests.post(f"{BASE_URL}/api/captcha/generate", json={
    "type": "math",
    "noise": 2
})
captcha_data = response.json()
captcha_id = captcha_data["id"]
svg_image = captcha_data["svg"]

print(f"Generated CAPTCHA ID: {captcha_id}")

# 2. Verify answer entered by user
user_answer = input("Enter CAPTCHA answer: ")

    "id": captcha_id,

This project is fully self-contained. The Express server serves both the REST API and the frontend UI.

Deploy on Render (Recommended)

100% Free Web Service

Render automatically detects Node.js and starts your web server with zero configuration.

  1. Push this code to your GitHub repository: git push origin main
  2. Log in to Render.com and click New + → Web Service.
  3. Select your Captcha-Generator repository.
  4. Settings are auto-filled from package.json:
    Build Command: npm install
    Start Command: npm start
  5. Click Create Web Service. In under 2 minutes, your live URL is active!
🚂

Deploy on Railway

Instant Git Sync

Railway provides instant continuous deployment from GitHub branches with custom domain support.

  1. Go to Railway.app.
  2. Click New Project → Deploy from GitHub repo.
  3. Select this repository. Railway reads the included Procfile and boots the server automatically.
  4. Under service Settings → Generate Domain to get a public URL.
